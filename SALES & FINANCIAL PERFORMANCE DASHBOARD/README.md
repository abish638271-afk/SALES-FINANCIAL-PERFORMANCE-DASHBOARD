# Sales & Financial Performance Dashboard

## 📊 Internship Task 4 – Dashboard Design

### Project Overview

This project focuses on designing an interactive Sales & Financial Performance Dashboard using Microsoft Power BI.

The dashboard provides a visual analysis of sales, profit, costs, products, regions, and customer segments to support business decision-making.

---

## 🎯 Objective

The main objective of this project is to create an interactive dashboard for business stakeholders.

The dashboard helps to:

- Monitor sales performance
- Analyze profit and cost
- Identify sales trends over time
- Compare regional performance
- Analyze customer segments
- Identify top-performing products
- Interactively filter business data

---

## 📁 Dataset

**Dataset Name:** Financial Sales Dataset

The dataset contains 10,000 records and includes information related to:

- Date
- Region
- Country
- Product Name
- Company Names
- Units Sold
- Unit Price
- Total Sales
- Cost of Goods Sold
- Profit
- Discount
- Customer Segment

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Microsoft PowerPoint

---

## 📌 Key Performance Indicators

The dashboard includes the following KPIs:

- Total Sales
- Total Profit
- Total Units Sold
- Total Cost

---

## 📈 Dashboard Visualizations

The dashboard contains:

1. Monthly Sales Trend
2. Sales by Region
3. Profit by Region
4. Sales by Customer Segment
5. Top 10 Products by Sales
6. Interactive Date Slicer
7. Interactive Region Slicer
8. Interactive Customer Segment Slicer

---

## 🎛️ Dashboard Interactivity

Users can interact with the dashboard using:

- Date filter
- Region filter
- Customer Segment filter

The visuals update dynamically based on the selected filters.
